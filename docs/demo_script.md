# 一分钟演示脚本

录制前运行 `python -m unittest discover -s tests -v`，保留真实测试结果。执行 `python webui.py --provider mock --open`，在“代码助手”页选择“离线规则引擎”。需要展示在线模型时，先自行配置 `.env` 并运行 `python main.py --check-api`，使用实际验证过的响应。

| 时间 | 操作 | 讲解要点 |
| --- | --- | --- |
| 0–8 秒 | 展示 README 的目标与架构 | 五个方向共用 Agent 主循环、模型适配器、工具注册表和记忆 |
| 8–25 秒 | 项目概览点击“扫描项目”，筛选高优先级，再点开一个问题 | 展示真实跨文件统计与源码行号，说明样例文件刻意包含问题 |
| 25–35 秒 | 导出扫描 JSON，切换 Git 改动页刷新 | 区分暂存与未暂存差异，说明工具只读 |
| 35–47 秒 | 代码助手选择解释模式，发送“解释 examples/clean_sample.py” | 同一界面选择任务模式，可使用同名会话继续上下文 |
| 47–55 秒 | 展示预先运行的测试结果和 Design.md | 测试覆盖主循环、会话、网络异常、工具边界与 Web 接口 |
| 55–60 秒 | 展示提交包 | 源码、README、设计文档和演示说明齐全 |

在线录制时明确说明实际使用的模型，不预先承诺模型一定会调用某个工具或发现某个特定问题。若使用离线模式，不将骨架生成描述为完整业务代码，不将跳过的测试当成业务验证成功。

录屏时不打开 `.env`，不要展示密钥。测试数量、运行耗时和静态评分以当前画面为准。若某次响应超过演示时长，可以展示提前运行并注明来源的报告，视频总时长控制在 60 秒以内。
