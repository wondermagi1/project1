# 项目工作流指南

## 打开项目

```bash
python webui.py --workspace "项目绝对路径" --open
```

打开本地工作台。无需在线模型时加上 `--provider mock`；只读检查可加上 `--read-only`。文件侧栏支持搜索和源码预览。

## 定位质量问题

在项目概览点击“扫描项目”，按严重度筛选问题。点击问题查看源码行，悬停查看修复建议，再使用“交给助手审查”进一步分析。

扫描不会执行代码。示例中的 `buggy_sample.py` 刻意包含问题，适合熟悉扫描流程；实际项目应结合测试与人工审查判断规则报告。

## 审查改动

工作区为 Git 仓库根目录时，可使用“扫描改动”缩小范围。在 Git 改动页刷新状态，查看暂存与未暂存差异，新文件通过预览查看内容。

选择“交给助手审查”会准备任务。发送后，在线模型可基于差异与受影响文件分析回归风险；离线模式提供差异证据。

## 验证与保存结果

在项目概览输入 unittest 测试目录，点击“运行测试”，检查失败、错误及跳过项。此操作会执行本机测试代码，受只读和禁止执行配置约束。

任务完成后下载 Markdown 报告或 JSON 轨迹，项目扫描也可导出 JSON。新建会话用于处理独立任务，历史会话可从下拉框恢复。

## 分发源码

```bash
python scripts/package.py
```

默认将源码与文档归档到 `dist/code-assistant-agent.zip`，排除本地配置、会话和生成产物。使用 `--package-name` 自定义名称，覆盖已有文件时添加 `--force`。
