## 使用边界

本次未连接真实在线模型，测试使用离线规则引擎或伪造 HTTP 响应。真实模型的生成质量、调用权限、速度与费用需在配置服务后单独验证。

静态分析不是完整程序验证。当前项目包含刻意出错的教学样例，因此项目概览出现高优先级问题符合样例设计。离线生成代码和测试主要是骨架，跳过项不算业务测试通过。

项目索引最多 500 个文本文件，默认扫描 100 个源文件。单个源码文件限 300 KB，扫描最多返回 500 条问题；Git 展示最多 100 个改动文件及 40,000 字符差异。超过范围会明确标记。

服务仅用于本地可信项目。测试执行使用当前用户权限，没有容器隔离。当前实现支持 unittest，尚未集成 pytest / Jest。未实现跨进程会话锁或 token 摘要。
